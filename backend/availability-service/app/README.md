Availability Service

This service is responsible for managing the availability of toilets in malls.

## Endpoints

### Malls

- GET /malls
- GET /malls/{mall_id}
- POST /malls
- PUT /malls/{mall_id}
- DELETE /malls/{mall_id}

### Toilets

- GET /malls/{mall_id}/toilets
- GET /malls/{mall_id}/toilets/{toilet_id}
- POST /malls/{mall_id}/toilets
- PUT /malls/{mall_id}/toilets/{toilet_id}
- DELETE /malls/{mall_id}/toilets/{toilet_id}
